3. Que dados são tratados?

3.1 Fotos para reconhecimento

Ao fotografar uma página de livro ou escolher uma foto, a imagem é enviada em JPEG por HTTPS criptografado a um Cloudflare Worker (nossa infraestrutura).

Importante: a foto pode conter dados pessoais – nomes, notas manuscritas, rostos. Fotografe apenas a página de vocabulário e certifique-se de que não apareçam pessoas, nomes ou notas pessoais. O app mostra um aviso antes de cada escaneio.

Cadeia de tratamento:
App → Cloudflare Worker → OpenRouter → provedor do modelo de IA → OpenRouter → Cloudflare Worker → App

Armazenamento: o fornecedor não armazena a imagem permanentemente. No Worker, a imagem é processada apenas em memória. Para a análise de IA, a imagem vai para OpenRouter Inc. e o provedor do modelo usado.

Zero Data Retention (ZDR): imposta tecnicamente. Apenas endpoints que não armazenam permanentemente entradas/saídas após o tratamento. Uso para treino/melhoria de modelos proibido (data_collection: "deny"). OpenRouter pode tratar metadados técnicos (modelo, tokens, duração, custos). Fallback para provedor sem ZDR é excluído.

3.2 Vocabulário e progresso

Vocabulário reconhecido, entradas manuais e seu progresso são armazenados localmente (SwiftData). Com iCloud, sincronizam via Apple CloudKit no iCloud privado do usuário. VokabelScan não mantém base própria de usuários.

3.3 Contadores de cota de escaneio

Para acompanhar entre dispositivos os escaneos gratuitos usados, o app guarda um contador (p. ex., « 3 de 5 ») no iCloud Key-Value Store e localmente. Sem nomes, e-mails ou identificadores diretos; atribuível ao usuário na relação Apple ID/dispositivo.

3.4 Assinaturas Premium

Compra e gestão via Apple StoreKit. Dados de pagamento ficam na Apple. O app sabe apenas se a assinatura está ativa. Sem dados de pagamento tratados pelo app ou fornecedor.

4. Tratamento no servidor (Cloudflare)

Dois tratamentos distintos :

4.1 Interface de IA (Cloudflare Worker)

A API roda em Cloudflare Workers. Dados de rede/requisição necessários são tratados. A imagem vai ao OpenRouter, sem armazenamento duradouro.

Base legal: Art. 6.1.b RGPD (execução do contrato).

4.2 Anti-abuso / limitação de taxa (Cloudflare Workers KV)

Seu endereço IP é guardado com a data como contador (scans:<IP>:<data>) no Workers KV a cada requisição. Excluído automaticamente após 48 h. O IP não é vinculado a outros dados nem usado para outros fins.

Base legal: Art. 6.1.f RGPD. Duração: máx. 48 h.

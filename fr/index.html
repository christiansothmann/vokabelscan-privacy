3. Quelles données sont traitées ?

3.1 Photos pour la reconnaissance du vocabulaire

Lorsque tu photographies une page de manuel ou choisis une photo, cette image est envoyée en JPEG via une connexion HTTPS chiffrée à un Cloudflare Worker (notre infrastructure serveur).

Important : une photo téléversée peut contenir des données personnelles – noms, notes manuscrites, visages ou autres informations sur la page. Ne photographie que la page de vocabulaire et assure-toi qu'aucune personne, nom ou note personnelle n'est visible. L'app affiche un avis avant chaque scan.

Chaîne de traitement :
App → Cloudflare Worker → OpenRouter → fournisseur du modèle d'IA → OpenRouter → Cloudflare Worker → App

Stockage : le fournisseur ne stocke pas l'image de manière permanente ni dans une base. Dans le Cloudflare Worker, l'image est traitée uniquement en mémoire. Pour l'analyse IA, l'image est transmise à OpenRouter Inc. et au fournisseur du modèle d'IA utilisé.

Zero Data Retention (ZDR) : la ZDR est imposée techniquement. Seuls des endpoints de fournisseurs d'IA qui ne stockent pas de manière permanente les entrées et sorties après traitement sont utilisés. En outre, l'utilisation du contenu pour l'entraînement ou l'amélioration des modèles est interdite (data_collection: "deny"). OpenRouter peut traiter des métadonnées techniques (modèle utilisé, nombre de tokens, durée, coûts). Un fallback vers un fournisseur sans ZDR est techniquement exclu.

3.2 Vocabulaire et progression

Le vocabulaire reconnu, les entrées créées manuellement et ta progression (statut, bonnes réponses, horodatages) sont stockés localement sur ton appareil (SwiftData).

Si iCloud est activé, ces données sont synchronisées via Apple CloudKit. Les données d'apprentissage sont stockées dans l'environnement iCloud privé de l'utilisateur. VokabelScan n'exploite pas sa propre base de données utilisateurs.

3.3 Compteurs de quota de scan

Pour suivre entre appareils le nombre de scans gratuits utilisés, l'app stocke un compteur (p. ex. « 3 sur 5 ») dans l'iCloud Key-Value Store et localement. Le compteur ne contient ni noms, ni e-mails, ni informations directement identifiantes. Il est cependant attribuable à l'utilisateur dans la relation Apple ID/appareil.

3.4 Abonnements Premium

L'achat et la gestion de l'abonnement Premium se font via Apple StoreKit. Toutes les données de paiement restent chez Apple. L'app sait uniquement si un abonnement est actif. Aucune donnée de paiement n'est traitée par l'app ou le fournisseur.

4. Traitement côté serveur (Cloudflare)

Deux traitements distincts :

4.1 Interface IA (Cloudflare Worker)

Notre API fonctionne via Cloudflare Workers. Des données réseau et de requête techniquement nécessaires sont traitées. L'image est transmise à OpenRouter et non stockée durablement.

Base légale : Art. 6.1.b RGPD (exécution du contrat).

4.2 Protection anti-abus / limitation de taux (Cloudflare Workers KV)

Ton adresse IP est stockée avec la date comme compteur (clé : scans:<IP>:<date>) dans Workers KV à chaque requête. Ce compteur est supprimé automatiquement après 48 h. L'IP n'est pas reliée à d'autres données ni utilisée à d'autres fins.

Base légale : Art. 6.1.f RGPD (intérêt légitime). Durée : 48 h max.

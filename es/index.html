3. ¿Qué datos se tratan?

3.1 Fotos para el reconocimiento de vocabulario

Cuando fotografiás una página de un libro de texto o eliges una foto, esa imagen se envía como JPEG mediante una conexión HTTPS cifrada a un Cloudflare Worker (nuestra infraestructura de servidores).

Importante: Una foto subida puede contener datos personales – nombres, notas manuscritas, rostros u otra información de la página fotografiada. Por favor, fotografía únicamente la página de vocabulario y asegúrate de que no se vean personas, nombres ni notas personales en la imagen. La app muestra un aviso correspondiente antes de cada escaneo.

Cadena de tratamiento:
App → Cloudflare Worker → OpenRouter → proveedor del modelo de IA → OpenRouter → Cloudflare Worker → App

Almacenamiento: El proveedor no almacena la imagen transmitida de forma permanente ni en una base de datos. En el Cloudflare Worker, la imagen se procesa únicamente en memoria para atender la solicitud. Para el análisis con IA, la imagen se transmite a OpenRouter Inc. y al proveedor del modelo de IA utilizado.

Zero Data Retention (ZDR): Para el tratamiento con IA se exige técnicamente Zero Data Retention. Así, solo se usan endpoints de proveedores de IA que no almacenan de forma permanente las entradas transmitidas ni las salidas generadas tras completar el tratamiento. Además, se prohíbe el uso de contenidos para el entrenamiento o mejora de modelos (data_collection: "deny"). OpenRouter puede tratar metadatos técnicos de la solicitud, como el modelo usado, el número de tokens, la duración del tratamiento y la información de costes. Un fallback a un proveedor sin capacidad ZDR queda técnicamente excluido.

3.2 Vocabulario y progreso de aprendizaje

El vocabulario reconocido, las entradas que crees manualmente y tu progreso de aprendizaje (estado, respuestas correctas, marcas de tiempo) se guardan localmente en tu dispositivo (SwiftData).

Si tienes iCloud activado, estos datos se sincronizan con tus otros dispositivos mediante Apple CloudKit. Los datos de aprendizaje sincronizados se guardan en el entorno iCloud privado del usuario. VokabelScan no mantiene aquí una base de datos propia de usuarios. El acceso se realiza a través del entorno iCloud de Apple proporcionado por el sistema operativo.

3.3 Contadores de cuota de escaneo

Para seguir entre dispositivos cuántos escaneos gratuitos has usado, la app guarda un contador (p. ej., «3 de 5») en el iCloud Key-Value Store y localmente en el dispositivo. El contador no contiene nombres, correos ni otra información directamente identificativa. No obstante, se guarda en el iCloud Key-Value Store personal del usuario y, por tanto, es atribuible al usuario dentro de la relación Apple ID/dispositivo.

3.4 Suscripciones Premium

La compra y gestión de la suscripción Premium se realiza a través de Apple StoreKit. Todos los datos de pago y transacción quedan en Apple. La app solo sabe si una suscripción está activa o no. La app ni el proveedor tratan datos de pago.

4. Tratamiento en el servidor (Cloudflare)

En Cloudflare se distinguen dos tratamientos separados:

4.1 Prestación de la interfaz de IA (Cloudflare Worker)

Nuestra API se opera mediante Cloudflare Workers. Se tratan datos de red y de solicitud técnicamente necesarios. La imagen subida se reenvía desde el Worker a OpenRouter y allí no la almacenamos de forma permanente.

Base jurídica: Art. 6.1.b RGPD (ejecución del contrato).

4.2 Protección contra abuso / limitación de tasa (Cloudflare Workers KV)

Para proteger contra el abuso automatizado y costes de API ilimitados, en cada solicitud de reconocimiento se guarda tu dirección IP – un dato personal – junto con la fecha como contador (clave: scans:<IP>:<fecha>) en Cloudflare Workers KV. Este contador se elimina automáticamente a las 48 horas. La dirección IP no se vincula con otros datos ni se usa para otros fines.

Base jurídica: Art. 6.1.f RGPD (interés legítimo). Interés legítimo: protección de la infraestructura técnica y limitación de los costes de API inducidos por abuso. Periodo de conservación: máx. 48 horas.

6. Encargados del tratamiento y terceros utilizados

La app utiliza los siguientes servicios de terceros, que actúan como encargados del tratamiento (Art. 28 RGPD) o como destinatarios adicionales dentro de la cadena de tratamiento:

6.1 Apple iCloud (CloudKit)

Sincronización de tus datos de aprendizaje y contadores de cuota. Los datos se guardan en la base de datos CloudKit privada del usuario y solo son accesibles mediante el Apple ID. Se aplica la política de privacidad de Apple.

6.2 Apple StoreKit

Gestión de suscripciones. Los datos de pago quedan en Apple; la app solo recibe el estado de la suscripción (activa/inactiva). Se aplica la política de privacidad de Apple.

6.3 Cloudflare Inc. (encargado del tratamiento)

Operación del worker de la API (tratamiento de la foto, reenvío a OpenRouter) y almacenamiento de los contadores de limitación de tasa en Workers KV. Un Data Processing Addendum (DPA) forma parte del contrato. Se aplica la política de privacidad de Cloudflare.

6.4 OpenRouter Inc. (encargado del tratamiento)

Para el reconocimiento de vocabulario con IA, la imagen se transmite a OpenRouter. OpenRouter reenvía la entrada al proveedor del modelo de IA utilizado para su tratamiento. El tratamiento se realiza bajo una configuración Zero Data Retention, de modo que los datos de imagen transmitidos no se almacenan en el proveedor del modelo más allá de lo necesario para atender la solicitud. Los proveedores de modelos conectados son destinatarios adicionales dentro de la cadena de tratamiento. Un DPA se incorpora mediante las condiciones de uso de OpenRouter. Se aplica la política de privacidad de OpenRouter.

Los enlaces a las políticas de privacidad de terceros complementan esta información, pero no sustituyen las obligaciones informativas aquí recogidas.

7. Transferencias de datos a terceros países

Cloudflare Inc. y OpenRouter Inc. son empresas de EE. UU. Al usar sus servicios, puede haber tratamiento de datos personales fuera del Espacio Económico Europeo (EEE).

Cuando los datos personales se traten fuera del Espacio Económico Europeo, la transferencia se realiza con base en una decisión de adecuación aplicable de la Comisión Europea o, cuando esta no sea aplicable, con base en garantías adecuadas conforme al Art. 46 RGPD, en particular las Cláusulas Contractuales Tipo de la Comisión Europea:

  • Cloudflare: Cláusulas Contractuales Tipo de la UE en el marco del Data Processing Addendum.
  • OpenRouter: Cláusulas Contractuales Tipo de la UE (Módulo 2 Responsable → Encargado) en el marco del DPA.

Qué base de adecuación adicional aplica en cada caso depende de la configuración contractual respectiva.

Competente es la autoridad de control de tu lugar de residencia o del lugar de establecimiento del responsable, presumiblemente el Centro Estatal Independiente de Protección de Datos de Schleswig-Holstein (ULD), Holstenstraße 98, 24103 Kiel, Alemania, https://www.datenschutzzentrum.de.

Además, puedes dirigir solicitudes al proveedor en cualquier momento (véase la sección 1). Esto vale en particular para información sobre tratamientos en el servidor (tratamiento de IP, reenvío a OpenRouter) no visibles en la app.

10. Niños y menores

La app también puede ser usada por menores. Para las funciones principales de la app no se requiere consentimiento bajo protección de datos como base jurídica; el tratamiento se basa en el Art. 6.1.b RGPD (ejecución del contrato). Cuando para funciones futuras concretas se requiera consentimiento, se tendrán en cuenta los requisitos legales especiales para menores conforme al Art. 8 RGPD. Las compras de suscripciones se gestionan vía Apple StoreKit.

Para proteger a los menores, la app muestra un aviso antes de cada escaneo indicando que se debe fotografiar únicamente la página de vocabulario y que no deben verse personas, nombres ni notas personales en la imagen.
